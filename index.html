01 / Get started

Three steps. No terminal.

For desktop Chrome, Edge and Brave.

  1. Download & extract

    Download the ZIP above. On Windows, right-click it and choose Extract All. Keep the extracted folder somewhere permanent. Find the folder containing manifest.json.

  2. Load the extension

    Open chrome://extensions, edge://extensions or brave://extensions. Enable Developer mode, choose Load unpacked and select the folder containing the manifest—not the ZIP.

  3. Open your chart

    Confirm the extension is enabled. Open or refresh your Made4Trading chart page. Complete any publisher login or license prompt. Verify behavior on a demo account before live use.

These are standard unpacked-extension steps based on the inspected manifest. Compatibility and successful trading operation have not been runtime-verified. Firefox and mobile browsers are not covered by this package.

03 / Useful answers

A little help,
when you need it.

Keep the extracted folder in place. Your browser loads the extension from that folder.

For licensing, trading or product support, use the publisher’s website. For guide corrections, open a GitHub issue. Never post credentials, account numbers or private trading information.

“Manifest file is missing”

Extract the ZIP first. Select the inner folder that directly contains manifest.json, not its parent folder. Do not rename files.

The extension loads, but nothing appears

Confirm it is enabled and refresh the Made4Trading chart page. Check the extension’s Errors panel, required site access and publisher licensing. Do not disable browser protections globally. Contact the publisher if errors persist.

How do I update?

Obtain a newer archive from the publisher, extract it to a permanent folder, remove the old unpacked extension and load the new folder. Refresh the chart page and recheck on a demo account. Do not assume unpacked installations update automatically.

How do I remove it?

Open your browser’s extensions page, find Trade From Chart and choose Remove. Refresh open chart tabs. You can then delete its extracted folder.

What permissions does it request?

The inspected manifest requests declarativeNetRequest and webRequest, with access to Made4Trading, features.tradenation.com and specified Trade From Chart API, licensing and WebSocket hosts. It injects code into Made4Trading chart pages and changes their Content-Security-Policy header. Read the manifest and publisher terms; this is not a full security audit.
