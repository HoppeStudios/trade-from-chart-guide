# Code of conduct

This community supports an independent installation guide. Be welcoming, patient and respectful of people with different backgrounds and levels of experience.

## Expected behavior

- Discuss the work, not personal characteristics. Offer specific, constructive feedback.
- Respect privacy and consent. Never share credentials, private messages, account details or trading information without permission.
- Keep issues and pull requests relevant to the guide. Avoid spam, unsolicited promotion and pressure to trade or donate.
- Do not harass, threaten, discriminate against or sexually target anyone.

## Reporting and response

Use an available private GitHub contact route offered by the Hoppe Studios maintainer. If none is available, open a minimal issue titled **Private contact requested** with only a request for a private contact route. **Do not include incident details, names, screenshots or personal information in that public issue.** A public issue is not a confidential reporting channel.

Maintainers will consider reports in context and may remove content, close or restrict discussions, or block participation to protect the community. They should handle sensitive information discreetly and disclose it only as needed to address a report. No response deadline or absolute confidentiality is promised.

This policy applies to this repository’s issues, pull requests and other project-managed GitHub discussions. For vulnerabilities, follow [the security policy](SECURITY.md) instead.
