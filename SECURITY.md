# Security policy

## Scope and support

This repository contains Hoppe Studios’ independent static installation guide, not the Trade From Chart extension. Report security problems in the guide, its links or its repository deployment configuration here. Fixes target the current guide source on the default branch; no support period or response-time guarantee is offered for older guide releases.

For vulnerabilities in Trade From Chart, Made4Trading or their services, use the affected publisher’s official security or support route. This project cannot fix or certify those products.

## Report privately

Use GitHub’s private vulnerability reporting form:

**https://github.com/HoppeStudios/trade-from-chart-guide/security/advisories/new**

If the form is unavailable or private reporting is not enabled, use an available private GitHub contact route offered by the maintainer. Otherwise, open a minimal public issue titled **Private security contact requested**, asking only for a private reporting route. **Do not post vulnerability details, proof-of-concept code, credentials, personal data or exploit links in that issue.** Wait for a private channel before sending sensitive information.

In the private report, describe the affected guide URL or file, potential impact and minimal reproduction steps. Include the guide revision or release when known. Redact secrets and account information; do not attach extension binaries or private trading data.

## Safe investigation

Keep testing limited to systems you own or are authorized to test. Do not access other people’s accounts, place trades, disrupt services or probe third-party infrastructure on this project’s behalf. Allow maintainers time to assess and coordinate a fix before public disclosure.

Manifest inspection, a published checksum and standard installation instructions are **not** a security audit, runtime verification or certification of the extension. A checksum comparison establishes matching bytes only. No bug bounty or paid assessment is offered.
